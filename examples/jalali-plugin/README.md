# پلاگین نمونه: تقویم شمسی 🇮🇷

یک پلاگین کامل و قابل اجرا برای دیپ‌سیک هارنس که ابزار `date_convert` را به عامل اضافه می‌کند — تبدیل دقیق تاریخ بین تقویم جلالی و میلادی با الگوریتم استاندارد و بدون وابستگی خارجی.

## اجرای سریع

```sh
# از ریشه مخزن، بعد از build کردن سورس dsh (آموزش ۰۲):
cd dsh
pnpm dsh web --patch ../examples/jalali-plugin/cordis.patch.yml
```

سپس در رابط وب (پورت 3080) بپرسید:

- «۲۵ اسفند ۱۴۰۴ چه روزی از سال میلادی است؟»
- «Convert 2026-03-21 to the Jalali calendar»

عامل باید ابزار `date_convert` را صدا بزند و پاسخ دقیق بدهد.

## فایل‌ها

| فایل | نقش |
|---|---|
| `index.js` | پلاگین کامل با کامنت فارسی — الگوریتم جلالی + تعریف ابزار |
| `cordis.patch.yml` | لایه پیکربندی که پلاگین را به ترکیب اضافه می‌کند |
| `package.json` | مانیفست باندل با کلید `dsh.bundle` |

## ساختار یادگیری

این نمونه عمداً کوچک اما «کامل از نظر الزامات» نوشته شده تا بتوانید از آن به‌عنوان قالب پلاگین‌های خودتان استفاده کنید:

1. مانیفست باندل (`dsh.bundle` → فایل patch)
2. لایه patch با `insert` سطر پلاگین
3. تزریق `['tools']` و ثبت ابزار با `ctx.tools.register`
4. پارامترها با `required` و `enum` (اعتبارسنجی خودکار)
5. جدایی خروجی متعارف (`execute`) و رندر مدل‌محور (`output.render`)

شرح مفصل هر بخش در [آموزش ۰۶ — ساخت پلاگین اختصاصی](../docs-fa/06-ساخت-پلاگین-اختصاصی.md).
