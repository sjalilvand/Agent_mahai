# آموزش ۰۲ — نصب گام‌به‌گام

این آموزش شما را از صفر تا اجرای کامل dsh همراهی می‌کند. مسیر نصب برای سه سیستم‌عامل (ویندوز، لینوکس، مک) جداگانه توضیح داده شده و در هر مرحله، راه‌حل مخصوص کاربران ایران (میرورهای npm و مدیریت پروکسی) هم ارائه می‌شود. اگر در میانه راه به خطا خوردید، مستقیم به [آموزش ۰۹ — رفع مشکلات رایج در ایران](09-رفع-مشکلات-رایج-ایران.md) بروید.

## گام ۱ — نصب Node.js (نسخه ۲۰ یا بالاتر)

dsh با ران‌تایم Node.js اجرا می‌شود. نسخه پیشنهادی **Node.js LTS (نسخه ۲۲ یا بالاتر)** است. برای بررسی نسخه نصب‌شده:

```sh
node --version
# خروجی باید چیزی شبیه v22.x.x یا بالاتر باشد
```

### ویندوز

دو راه دارید. راه ساده: به صفحه رسمی [nodejs.org/en/download](https://nodejs.org/en/download) بروید و نصب‌کننده MSI نسخه LTS را دانلود و اجرا کنید. اگر دانلود از سایت رسمی برایتان کند یا ناموفق بود (تحریم)، دو جایگزین دارید:

- **میرور ایرانی:** سایت‌های میرور داخلی مانند `nodejs.ir` نسخه‌های رسمی را بدون تحریم ارائه می‌دهند.
- **مدیریت‌گر بسته winget:** در PowerShell اجرا کنید:

```powershell
winget install OpenJS.NodeJS.LTS
```

پس از نصب، یک پنجره ترمینال جدید باز کنید تا متغیر PATH به‌روز شود، سپس `node --version` را تست کنید.

### لینوکس (اوبونتو/دبیان)

بهترین روش، استفاده از NodeSource است:

```sh
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
```

اگر `curl` به گیت‌هاب یا NodeSource دسترسی ندارد، از مخازن خود توزیع هم می‌توانید نصب کنید (`sudo apt install nodejs npm` — هرچند ممکن است نسخه قدیمی‌تر باشد) یا از `nvm` استفاده کنید:

```sh
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
source ~/.bashrc
nvm install --lts
```

### مک

```sh
brew install node
```

یا نصب‌کننده PKG از سایت رسمی nodejs.org.

## گام ۲ — تنظیم میرور npm برای ایران (اختیاری اما توصیه‌شده)

رجیستری رسمی npm (`registry.npmjs.org`) برای کاربران ایران گاهی کند است یا درخواست‌ها را محدود می‌کند. میرورهای ایرانی نسخه‌های کامل بسته‌ها را نگه می‌دارند و سرعت دانلود در داخل کشور به‌مراتب بالاتر است. میرور معتبر و پرکاربرد: `https://registry.npmjs.ir`

### تنظیم دائمی برای npm

```sh
npm config set registry https://registry.npmjs.ir/
```

برای برگرداندن به حالت رسمی: `npm config set registry https://registry.npmjs.org/`

### تنظیم دائمی برای pnpm

اگر قصد دارید dsh را از سورس بسازید، به pnpm هم میرور را بدهید:

```sh
pnpm config set registry https://registry.npmjs.ir/ --global
```

یا فایل `.npmrc` را در ریشه پروژه بسازید (قالب آماده در [`scripts/npmrc-iran`](../scripts/npmrc-iran) موجود است):

```ini
registry=https://registry.npmjs.ir/
```

### بررسی صحت تنظیمات

```sh
npm config get registry
# باید https://registry.npmjs.ir/ را نشان دهد
npm ping
# باید pong برگرداند
```

نکته: اسکریپت `scripts/setup-iran.sh` (لینوکس/مک/WSL) و در ویندوز `scripts/setup-iran.bat` (ساده‌ترین راه) یا `scripts/setup-iran.ps1` تمام این تنظیمات را به‌صورت خودکار انجام می‌دهند. در ویندوز فایل `.ps1` را بدون فلگ `-ExecutionPolicy Bypass` اجرا نکنید و اسکریپت `.sh` را هرگز در ویندوز اجرا نکنید — توضیح کامل در [آموزش ۰۹، بخش ۸](09-رفع-مشکلات-رایج-ایران.md). اگر ترجیح می‌دهید همه‌چیز دستی کنترل‌شده باشد، همین بخش را دنبال کنید.

## گام ۳ — اجرای dsh (روش ساده: npx)

نیازی به «نصب» جداگانه نیست؛ npx بسته را یک‌بار دانلود و کش می‌کند و از دفعات بعد از کش اجرا می‌شود:

```sh
npx @deepseek-ai/dsh web
```

رفتار مورد انتظار:

1. اولین اجرا ممکن است ۱ تا ۳ دقیقه طول بکشد (دانلود بسته).
2. پیام راه‌اندازی رابط وب نمایش داده می‌شود و مرورگر به‌طور خودکار روی `http://127.0.0.1:3080` باز می‌شود.
3. برای اجرای سرور بدون باز شدن مرورگر: `npx @deepseek-ai/dsh web --no-open`

### نصب دائمی (اختیاری)

اگر می‌خواهید dsh همیشه در دسترس باشد:

```sh
npm install -g @deepseek-ai/dsh
dsh web
```

### پوستهٔ فارسی رابط وب (ماه‌ای)

رابط وب پیش‌فرض انگلیسی و چپ‌چین است. برای فارسی‌سازی کامل منوها، راست‌چین‌شدن صفحه، فونت وزیرمتن، تم آبی لوگو و نشان «ماه‌ای — ماه‌افزار هوشمند رسا»، پوستهٔ ماه‌ای را اعمال کنید:

```sh
# لینوکس / مک / WSL
bash scripts/patch-mahai-ui.sh

# ویندوز (PowerShell)
powershell -ExecutionPolicy Bypass -File scripts\patch-mahai-ui.ps1
```

سپس مرورگر را با `Ctrl+F5` تازه‌سازی کنید. اگر dsh هنوز دانلود نشده باشد، پچ پیام می‌دهد — اول یک‌بار `npx @deepseek-ai/dsh web` را اجرا کنید و بعد پچ را بزنید. اجرای اسکریپت `setup-iran` این گام را خودکار انجام می‌دهد؛ جزئیات بیشتر در آموزش ۰۹ (بخش ۷-۱).

## گام ۴ — (اختیاری) نصب از سورس برای توسعه‌دهندگان

چون این مخزن سورس کامل را در پوشه `dsh/` دارد، می‌توانید مستقیم از سورس بسازید — برای مطالعه کد، توسعه پلاگین یا مشارکت مفید است:

```sh
cd dsh
pnpm install
pnpm run build
pnpm dsh web
```

نصب pnpm (در صورت نداشتن):

```sh
npm install -g pnpm
```

نکات مهم برای کاربران ایران در این مرحله:

- قبل از `pnpm install` مطمئن شوید میرور npm تنظیم شده (گام ۲). فایل `pnpm-lock.yaml` در سورس، نسخه دقیق بسته‌ها را ثبت کرده و دانلود آن‌ها از میرور مشکلی ندارد.
- اگر برخی بسته‌ها از میرور یافت نشدند (به‌روزرسانی تأخیری میرور)، موقتاً به رجیستری رسمی با پروکسی برگردید: راه‌حل در آموزش ۰۹.
- برخی وابستگی‌های native (مثل ripgrep بسته‌بندی‌شده) از گیت‌هاب دانلود می‌شوند؛ اگر این مرحله خطای شبکه گرفت، متغیرهای پروکسی را تنظیم کنید (بخش پروکسی آموزش ۰۹).

## گام ۵ — تأیید نصب

بعد از راه‌اندازی موفق رابط وب:

1. مرورگر روی `http://127.0.0.1:3080` باز می‌شود و صفحه اصلی dsh را می‌بینید.
2. در آموزش ۰۳ یاد می‌گیرید مدل را وصل کنید و اولین مکالمه را شروع کنید.
3. برای تست خط فرمانی سریع، حالت headless عالی است:

```sh
npx @deepseek-ai/dsh headless "سلام! خودت را معرفی کن"
```

پاسخ مدل در stdout چاپ می‌شود. اگر پاسخ گرفتید، نصب شما کامل است.

## جمع‌بندی مسیر نصب

| مرحله | دستور | وضعیت لازم |
|---|---|---|
| Node.js | `node --version` | v20+ (ترجیحاً ۲۲ LTS) |
| میرور npm | `npm config get registry` | `https://registry.npmjs.ir/` |
| اجرا | `npx @deepseek-ai/dsh web` | باز شدن صفحه وب روی پورت 3080 |
| از سورس | `pnpm install && pnpm run build && pnpm dsh web` | برای توسعه‌دهندگان |
