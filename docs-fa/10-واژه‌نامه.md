# آموزش ۱۰ — واژه‌نامه اصطلاحات

مرجع سریع ترجمه اصطلاحات فنی این پروژه. برای هر اصطلاح، ترجمه فارسی مصوب این مخزن + توضیح یک‌خطی. ترتیب: الفبایی انگلیسی.

## مفاهیم پایه عامل‌محور

| اصطلاح | معادل فارسی این مخزن | توضیح |
|---|---|---|
| Agent | عامل | برنامهای که مدل را با ابزار و چرخه تصمیم به کنش‌گر تبدیل می‌کند |
| Agent Harness | بستر عامل | بستر اجرایی که عامل را تجهیز و کنترل می‌کند (مثل dsh) |
| LLM | مدل زبانی بزرگ | هسته تصمیم‌گیری و تولید متن عامل |
| Tool | ابزار | قابلیت مشخص و قابل فراخوانی مدل (bash، read، web_search و...) |
| Tool Call | فراخوانی ابزار | درخواست مدل برای اجرای یک ابزار با ورودی مشخص |
| Tool Result | نتیجه ابزار | خروجی برگشتی ابزار به مکالمه |
| Subagent | زیرعامل / عامل فرزند | عاملی که توسط عامل دیگری برای وظیفه‌ای تفویض می‌شود |
| Session | نشست | یک مکالمه/اجرای کامل با تاریخچه ذخیره‌شدنی |
| Workspace | فضای کاری | پوشه پروژه‌ای که عامل در آن اجازه کار دارد |
| Deliverable | دستیافتنی | خروجی نهایی قابل تحویل (فایل، گزارش، برنامه) |
| System Prompt | پرامپت سیستم | دستورالعمل پنهانی که رفتار عامل را جهت می‌دهد |
| Permission Mode | حالت مجوز | سیاست تأیید اعمال (چه چیزی نیاز به تأیید کاربر دارد) |
| Sandbox | جعبه‌شنی / سندباکس | محیط اجرای محدود برای کاهش ریسک |
| Headless | بدون‌رابط | اجرای یک‌وظیفه‌ای بدون UI؛ مناسب اسکریپت و CI |
| Job | کار (پس‌زمینه) | پروسه در حال اجرا در پس‌زمینه با خروجی قابل پیگیری |
| Schedule | زمان‌بندی | اجرای خودکار در زمان‌های مشخص (cron و...) |
| Goal | هدف | هدف کلان قابل پیگیری با چرخه‌های حالت |
| Workflow | گردش کار | اجرای ساختاریافته چندمرحله‌ای |

## مفاهیم معماری و Cordis

| اصطلاح | معادل فارسی | توضیح |
|---|---|---|
| Plugin | پلاگین | ماژول قابلیت با تابع apply که به زمین وصل می‌شود |
| Everything is a Plugin | «همه‌چیز پلاگین است» | فلسفه معماری dsh — هر قابلیت جایگزین‌پذیر |
| Context (ctx) | زمینه | آبجکت اشتراکی Cordis که پلاگین‌ها از طریق آن سرویس می‌گیرند/می‌دهند |
| Service | سرویس | قابلیت ثبت‌شده در زمینه (مثل ctx.tools، ctx.fs، ctx.shell) |
| Dependency Injection | تزریق وابستگی | اعلام نیاز پلاگین با آرایه `inject` و آماده‌سازی خودکار |
| Event | رویداد | پیام منتشرشده در زمین (مثل fs/observed، tool/call) |
| Bundle | باندل | بسته npm حامل یک لایه پیکربندی (dsh.bundle) |
| Profile | پروفایل | ترکیب قابل اجرای باندل‌ها و پچ‌های کاربر |
| Patch | پچ/لایه | فایل YAML تغییردهنده ترکیب (insert/override سطر پلاگین) |
| Overlay | لایه هم‌پوشان | هر پچ اعمال‌شده روی پشته پیکربندی |
| Layer Order | ترتیب لایه‌ها | ترتیب اعمال پچ‌ها؛ لایه بعدی قبلی را override می‌کند |
| Inspect | بازرسی | مشاهده فقط‌خواندنی درخت زمان اجرا (cordis_inspect_*) |
| Creators mode | حالت سازندگان | پروفایل بازرسی برای توسعه‌دهندگان پلاگین |
| Composability | ترکیب‌پذیری | توان ساختن سیستم بزرگ از قطعات مستقل و قابل‌تعویض |
| Canonical value | مقدار متعارف | خروجی خام و ساختاریافته ابزار قبل از رندر |
| Render | رندر | تبدیل مقدار متعارف به محتوای مدل‌محور/UI |

## مفاهیم وب، مدل و شبکه

| اصطلاح | معادل فارسی | توضیح |
|---|---|---|
| Provider | ارائه‌دهنده (مدل) | سرویس‌دهنده مدل زبانی (DeepSeek، OpenAI و...) |
| API Key | کلید API | رمز احراز هویت سرویس مدل |
| Base URL | آدرس پایه | ریشه HTTP سرویس ارائه‌دهنده |
| OpenAI-compatible | سازگار با OpenAI | پروتکل API مشابه Chat Completions اوپن‌ای‌آی |
| MCP (Model Context Protocol) | پروتکل زمینه مدل | استاندارد اتصال ابزار/منابع خارجی به عامل |
| Relay / Gateway | دروازه واسط | سرویس واسط بین شما و ارائه‌دهنده مدل |
| Web UI | رابط وب | محیط مرورگری dsh روی پورت 3080 |
| TUI | رابط متنی | محیط ترمینالی تعاملی |
| ACP | پروتکل کلاینت عامل | پروتکل stdio برای اتصال ادیتور/کلاینت‌های اتوماسیون |
| Registry (npm) | رجیستری بسته | مخزن بسته‌های npm (رسمی یا میرور) |
| Mirror | میرور | کپی محلی/منطقهای رجیستری برای سرعت و دسترس‌پذیری |
| Proxy | پروکسی | واسط شبکه برای عبور از محدودیت‌ها |
| PTY | پایودو-ترمینال | شبیه‌سازی ترمینال واقعی برای shell تعاملی |
| LSP | پروتکل سرور زبان | استاندارد قابلیت‌های زبان‌محور (تعریف، خطاها، تکمیل) |
| PTC | فراخوانی ابزار برنامه‌ای | اجرای کدی که چند ابزار را ترکیب می‌کند (run_code) |

## مجوزها و ایمنی

| اصطلاح | معادل فارسی | توضیح |
|---|---|---|
| Full access | دسترسی کامل | بالاترین سطح مجوز — خطرناک، فقط محیط ایزوله |
| Approval prompt | درخواست تأیید | پرسیدن از کاربر قبل از عمل حساس |
| Write-only credential | اعتبارنامه فقط‌نوشتنی | کلیدی که بعد از ذخیره هرگز نمایش داده نمی‌شود |
| Breaking change | تغییر ناسازگارکننده | تغییر نسخه که رفتار قبلی را می‌شکند |
| Developer preview | پیش‌نمایش توسعه‌دهنده | مرحله قبل از پایداری؛ API ممکن است عوض شود |
| engines.dsh | الزام نسخه dsh | محدوده سمنور سازگاری باندل با نسخه dsh |
