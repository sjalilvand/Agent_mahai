نصب گام‌به‌گام

از صفر تا اجرای کامل dsh در سه سیستم‌عامل — با راه‌حل‌های مخصوص ایران در هر گام.

محتوای این صفحه

۱. نصب Node.js ۲. میرور npm ایران ۳. اجرای dsh ۴. نصب از سورس ۵. اسکریپت خودکار ۶. تأیید نصب

نصب Node.js (نسخه ۲۰ یا بالاتر)

dsh با Node.js اجرا می‌شود؛ نسخه LTS (۲۲ یا بالاتر) پیشنهاد می‌شود. بررسی نسخه:

node --version

ویندوز: نصب‌کننده MSI از nodejs.org یا winget install OpenJS.NodeJS.LTS — اگر دانلود از سایت رسمی با تحریم گیر کرد، میرور داخلی nodejs.ir را امتحان کنید.
لینوکس (اوبونتو):

curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - sudo apt-get install -y nodejs

مک: brew install node

تنظیم میرور ایرانی npm

رجیستری رسمی برای IP ایران گاهی کند یا محدود است. میرور registry.npmjs.ir نسخه کامل بسته‌ها را سریع می‌دهد:

npm config set registry https://registry.npmjs.ir/ npm ping

برای pnpm (نصب از سورس):

pnpm config set registry https://registry.npmjs.ir/ --global
💡
برگشت به حالت رسمی: npm config set registry https://registry.npmjs.org/ یا bash scripts/setup-iran.sh --restore

اجرای dsh با یک دستور

نیازی به نصب جداگانه نیست؛ npx بسته را یک‌بار دانلود و کش می‌کند:

npx @deepseek-ai/dsh web

رابط وب روی http://127.0.0.1:3080 بالا می‌آید. برای سرور بدون دسکتاپ: --no-open. نصب دائمی اختیاری:

npm install -g @deepseek-ai/dsh dsh web

نصب از سورس (توسعه‌دهندگان)

سورس کامل در پوشه dsh/ همین مخزن است — برای مطالعه کد و توسعه پلاگین:

cd dsh pnpm install pnpm run build pnpm dsh web
⚠️
قبل از pnpm install میرور را تنظیم کنید. اگر برخی بسته‌ها از میرور یافت نشدند یا باینری‌های native از گیت‌هاب دانلود نشدند، متغیرهای پروکسی را تنظیم کنید (صفحه رفع مشکلات). نکته: میرور ایران بسته‌های scoped مانند @deepseek-ai/dsh را گاهی ندارد — در این صورت میرور چینی registry.npmmirror.com را تنظیم کنید (صفحه رفع مشکلات).

اسکریپت خودکار بومی‌سازی

همه گام‌های بالا (میرور + پروکسی + اجرا) با یک دستور:

# لینوکس / مک / WSL bash scripts/setup-iran.sh # ویندوز — ساده‌ترین راه (ExecutionPolicy خودکار بای‌پس می‌شود) .\scripts\setup-iran.bat # ویندوز — فراخوانی مستقیم PowerShell powershell -ExecutionPolicy Bypass -File scripts\setup-iran.ps1 # با پروکسی PROXY=http://127.0.0.1:8118 bash scripts/setup-iran.sh

تأیید نصب

رابط وب باز شد؟ عالی. تست خط فرمانی سریع هم داریم — پاسخ مدل مستقیم در ترمینال چاپ می‌شود:

npx @deepseek-ai/dsh headless "سلام! خودت را معرفی کن"
ℹ️
برای اتصال مدل (کلید DeepSeek یا دروازه واسط ایرانی) به آموزش ۰۳ در docs-fa/ مراجعه کنید — این مرحله پس از باز شدن رابط وب انجام می‌شود.
