محتوای این صفحه

کلون مخزن چرخه روزمره حل تعارض کار تیمی امنیت توکن به‌روزرسانی dsh

کلون مخزن روی سیستم خودتان

نصب گیت، سپس تنظیمات اولیه یک‌باره:

git config --global user.name "نام شما" git config --global user.email "email@example.com" git config --global init.defaultBranch main

کلون ساده (مخزن عمومی):

git clone https://github.com/sjalilvand/Agent_mahai.git cd Agent_mahai

اگر مخزن خصوصی شد یا برای push مشکل احراز هویت گرفتید، توکن در URL:

git clone https://<USERNAME>:<TOKEN>@github.com/sjalilvand/Agent_mahai.git
⚠️
توکن در URL در .git/config ذخیره می‌شود. برای کار طولانی‌مدت از SSH استفاده کنید (ssh-keygen -t ed25519 و افزودن کلید عمومی در Settings → SSH keys) — هیچ توکنی جابه‌جا نمی‌شود.

چرخه روزمره: branch → edit → commit → push → pull

شاخه بسازید — حتی تنهایی

هر قابلیت/اصلاح یک شاخه؛ main همیشه سالم بماند:

git switch -c feature/portal-search

قرارداد نام‌گذاری: feature/ قابلیت · fix/ اصلاح · docs/ مستندات · update/ به‌روزرسانی dsh

تغییرات را ثبت کنید

commit کوچک و موضوعی؛ پیام با قالب «نوع: خلاصه»:

git status git add docs-fa/ git commit -m "docs: به‌روزرسانی آموزش ۰۴ با ابزارهای جدید"

دریافت و ارسال

قبل از شروع کار و قبل از push، همیشه pull:

git pull --rebase origin main git push -u origin feature/portal-search

حل تعارض بدون استرس

وقتی دو طرف یک خط را عوض کرده باشند، گیت توقف می‌کند و در فایل نشانه‌ها را می‌گذارد: <<<<<<< HEAD / ======= / >>>>>>>. نسخه درست را دستی بنویسید، نشانه‌ها را حذف کنید و:

git add <file> git rebase --continue # فرار در وسط راه: git rebase --abort

کار تیمی چندنفره

محافظت از main

گیت‌هاب → Settings → Branches → protection: push مستقیم ممنوع، حداقل یک review الزام.

Pull Request برای همه‌چیز

شاخه را push کنید، PR باز کنید، همکار مرور و تأیید کند، سپس Squash merge و حذف شاخه.

همگام‌سازی بعد از merge

git switch main git pull --rebase origin main git remote prune origin

تگ نسخه‌های پایدار

git tag -a v1.0.0 -m "نسخه ۱.۰.۰" git push --tags

قانون طلایی: توکن در کد، مستندات، اسکرین‌شات یا پیام عمومی — هرگز. توکنی که در گفتگو اشتراک شده، بعد از کار حتماً از GitHub → Settings → Developer settings باطل کنید و توکن تازه با محدوده حداقلی بسازید.

به‌روزرسانی پوشه dsh از مخزن رسمی

لایه بومی‌سازی شما حفظ می‌شود و فقط سورس عوض می‌شود:

git switch -c update/dsh-latest rm -rf dsh git clone --depth 1 https://github.com/deepseek-ai/deepseek-harness.git dsh-tmp rm -rf dsh-tmp/.git mv dsh-tmp dsh git add dsh git commit -m "update: همگام‌سازی سورس dsh با مخزن رسمی" git push -u origin update/dsh-latest
ℹ️
قبل از merge: pnpm install && pnpm run build && pnpm dsh web را تست کنید تا سازگاری با مستندات فارسی حفظ شود.
