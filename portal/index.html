در ۵ دقیقه اجرا کنید

۱️⃣ نصب Node.js (نسخه ۲۰+)

از سایت رسمی یا میرورهای ایرانی — آموزش کامل گام‌به‌گام در صفحه نصب.

node --version

۲️⃣ تنظیم میرور ایران (توصیه‌شده)

برای سرعت دانلود بسته‌ها در داخل کشور:

npm config set registry https://registry.npmjs.ir/

۳️⃣ اجرای dsh

رابط وب روی پورت ۳۰۸۰ بالا می‌آید:

npx @deepseek-ai/dsh web

۴️⃣ یا اسکریپت تک‌دستوری

لینوکس/مک: bash scripts/setup-iran.sh
ویندوز: scripts\setup-iran.ps1

⚠️
هشدار ایمنیdsh در مرحله پیش‌نمایش توسعه‌دهنده است، ممیزی امنیتی نشده و می‌تواند کد اجرا کند. با کمترین دسترسی ممکن، ترجیحاً در ماشین مجازی یا کانتینر اجرا کنید و قبل از تأیید هر دستور، آن را مرور کنید.

پورتال کاملاً آفلاین کار می‌کند

با پایتون یا نود

cd portal python3 -m http.server 8080 # یا: npx serve .

سپس http://localhost:8080 را باز کنید.

یا مستقیم در مرورگر

فایل portal/index.html را دابل‌کلیک کنید — همه‌چیز (فونت، استایل، اسکریپت) محلی است.

💡
پورتال را می‌توانید با GitHub Pages هم منتشر کنید: Settings → Pages → شاخه main و پوشه /portal.
