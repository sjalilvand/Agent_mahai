# 🇮🇷 عامل‌های هوشمند ایران — Agent_mahai

نسخه **بومی‌سازی‌شده برای ایران** از پروژه [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (dsh) — یک بستر عامل هوشمند (Agent Harness) متن‌باز با معماری «**همه‌چیز پلاگین است**»، همراه با مستندات کامل فارسی، پورتال آموزشی، اسکریپت‌های نصب مخصوص ایران و راهنمای رفع مشکلات شبکه و تحریم.

> ⚠️ **هشدار ایمنی (حتماً بخوانید):** پروژه dsh در مرحله «پیش‌نمایش توسعه‌دهنده» است، هنوز ممیزی امنیتی نشده و می‌تواند کدهای تولیدشده توسط مدل را اجرا کند. پیش از استفاده، فایل [ایمنی](dsh/SAFETY.md) را مطالعه کنید، با کمترین دسترسی ممکن اجرا کنید و از محیط ایزوله (ماشین مجازی یا کانتینر) استفاده نمایید. نسخه فارسی این هشدار در [آموزش ۰۱](docs-fa/01-معرفی-دیپ‌سیک-هارنس.md) آمده است.

## 🚀 شروع سریع (۵ دقیقه)

### پیش‌نیاز
- نصب **Node.js** نسخه ۲۰ یا بالاتر → [آموزش نصب کامل](docs-fa/02-نصب-گام-به-گام.md)

### اجرا با یک دستور

```sh
npx @deepseek-ai/dsh web
```

رابط وب در آدرس `http://127.0.0.1:3080` بالا می‌آید و به‌صورت خودکار در مرورگر باز می‌شود. اگر می‌خواهید مرورگر باز نشود:

```sh
npx @deepseek-ai/dsh web --no-open
```

### اگر npx کند بود یا خطای شبکه گرفتید (مخصوص ایران)

```sh
# اسکریپت آماده بومی‌سازی — میرور npm ایران + تنظیمات پروکسی

# ویندوز — ساده‌ترین راه (سیاست اجرا خودکار بای‌پس می‌شود):
.\scripts\setup-iran.bat

# ویندوز — فراخوانی مستقیم PowerShell:
powershell -ExecutionPolicy Bypass -File scripts\setup-iran.ps1

# لینوکس / مک / WSL:
bash scripts/setup-iran.sh

# سپس دوباره:
npx @deepseek-ai/dsh web
```

> ⚠️ **دو خطای رایج ویندوز و راه‌حل:**
> 1. «running scripts is disabled on this system» → اجرای اسکریپت PowerShell قفل است؛ از `setup-iran.bat` استفاده کنید یا فلگ `-ExecutionPolicy Bypass` را اضافه کنید.
> 2. «set: pipefail: invalid option name» → اسکریپت `.sh` را در ویندوز اجرا کرده‌اید (مشکل CRLF). در ویندوز فقط `.bat`/`.ps1` را اجرا کنید؛ `.sh` مخصوص لینوکس/مک/WSL است.
>
> توضیح کامل: [آموزش ۰۹، بخش ۸](docs-fa/09-رفع-مشکلات-رایج-ایران.md)

راهنمای کامل رفع خطاهای شبکه و تحریم: [آموزش ۰۹ — رفع مشکلات رایج در ایران](docs-fa/09-رفع-مشکلات-رایج-ایران.md)

## 🖥 پورتال وب مستندات

پورتال فارسی این پروژه به‌صورت **کاملاً آفلاین** کار می‌کند (فونت وزیرمتن به‌صورت محلی بارگذاری می‌شود و هیچ وابستگی به سرویس‌های خارجی ندارد):

```sh
cd portal
# یکی از این روش‌ها:
python3 -m http.server 8080        # با پایتون
npx serve .                         # با نود
# یا ساده‌تر: فایل index.html را مستقیم در مرورگر باز کنید
```

سپس در مرورگر: `http://localhost:8080`

صفحات پورتال: خانه، نصب، کاتالوگ ابزارها، پلاگین‌نویسی، رفع مشکلات ایران، گردش کار گیت.

## 🛠 اسکریپت‌های بومی‌سازی ایران

| اسکریپت | سیستم‌عامل | کار |
|---|---|---|
| `scripts/setup-iran.bat` | ویندوز (ساده‌ترین راه) | لانچر یک‌کلیکی؛ PowerShell را با `-ExecutionPolicy Bypass` اجرا می‌کند |
| `scripts/setup-iran.sh` | لینوکس / مک / WSL | تنظیم میرور npm ایران برای npm و pnpm، پشتیبانی پروکسی، نصب و اجرای dsh |
| `scripts/setup-iran.ps1` | ویندوز (PowerShell) | همان عملکرد بالا برای ویندوز — بدون `.bat` باید با فلگ `-ExecutionPolicy Bypass` اجرا شود |
| `scripts/npmrc-iran` | همه | قالب آماده `.npmrc` با میرور ایران |
| `scripts/proxy-env.sh` | لینوکس / مک | قالب متغیرهای محیطی پروکسی |
